# 全地下室车道净高（2026-10-03）

命令：

```
lwp lanes <调整后.slbh> --compare <调整前.slbh> --drawings drawings_b1.json --out <目录>
```

结果在 `eval/yongjing-basement/lanes/`：
- `index.html`：分档面积、两张平面图、各车道表；
- `lanes.json`：含每条车道每米的净高剖面；
- `map_after.png`：调整后平面图。

## 口径

| 项 | 口径 |
| --- | --- |
| 净高 | 地下一层楼面（B1F，+1.600）至上方最低的机电或结构底。机电含保温、管件、阀门、喷头 |
| 车道 | 图纸“车道流线”两侧各 2.75 m（车道宽 5.5 m），扣除车位。49 条车道，约 6600 m² |
| 车道剖面 | 沿车道每 1 m 取横向最低值 |
| 分级 | 50 mm 一档，占车道长度 ≥ 5 % 的净高 |
| 变化次数 | 100 mm 一档，短于 3 m 的段并入相邻段后，沿车道的净高变化次数 |

注意：
- 楼面统一取 B1F 标高，未考虑局部降板和坡道。
- 上方没有机电和梁的格子，在图中标为“无机电、梁”，不参与统计。

## 人工方案的车道净高特点

1. **主档 2.55–2.70 m：** 约一半车道长度在这一档；调整前主档为 2.45–2.55 m。人工方案把车道净高普遍提高了约 0.1–0.15 m。
2. **局部低点 2.48 m：** 很多车道的最低点都是 2.48 m，如 X01、X03、X07、X13、X19、X21、X24、X26、Y33、Y37、Y43、Y45。控制构件几乎都是横穿车道的排烟（兼排风）风管，截面 1600×320 或 2100×320。人工方案把这类风管统一放在同一标高，这是事实上的风管控制标高。
3. **更低点 2.33–2.43 m：** 共 8 条车道，如 X17、X22、Y31、Y34、Y35、Y39、Y40。均为风管附件（风阀等）、人防送风、送风风管处的局部低点，长度短，但都在 2.2 m 以上。
4. **高区 2.85 m 以上：** 约 24 % 的长度，多为没有管线束经过的车道段。
5. **均匀性：** 每条车道的净高变化次数中位为 3（调整前为 2）。人工方案不追求同一数值，而是“主档 + 风管处局部降低 + 无管线处抬高”。

## 对自动方案的启示

1. **车道净高目标：**
   - 人工方案的主档约 2.60 m，风管处约 2.48 m；
   - 第 17 节迭代求解后，走廊 C 只有 2.35 m，明显偏低；
   - 自动方案应以“车道主档不低于人工方案”为目标，横穿风管处单独控制。
2. **风管控制标高：** 宽扁的排烟风管（320 高）横穿车道是车道净高的主要控制因素。可以考虑把风管作为固定的标高层（全地下室统一），管线束在风管之上或之间排布。
3. **分级的研讨依据：** 下一步可以按车道组（环线、主通道、支通道）给出各组的主档净高，作为方案研讨的基础数据。
