## 3. 导出问题（v0.4.1 已修复）

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 链接模型标高差 6.65 m | `Level.Elevation` 相对高程基准，链接模型基准在 6.65 m | 改用 `ProjectElevation`（内部原点） |
| 保温诊断 1250 条 | 对桥架等不能带保温的构件调用了保温接口 | 仅对管道、风管及其管件、附件读取 |
| 桥架配件无管件类型 | 桥架配件不是 MechanicalFitting | 从族参数读取 |

## 4. 需要确认的模型情况

1. **模型中没有保温层**（两个包均为 0）。净距计算需要按系统给默认保温厚度，还是按项目标准不考虑保温？
2. **桥架没有系统和服务类型**，只能按类型名分类（强电消防桥架、火灾自动报警、充电桩桥架、强电-非居、母线、弱电桥架、消防广播、高压、UPS 等）。
3. **系统缩写含义**需要按项目确认，用于“有压让无压”等排布规则：
   X、ZP / ZP1、XW、J0 / J1 / J2 / J3、JZ2、JS1 / JS2、JG、YF、F、PY/F、PY、PF、JY。
4. 管线内部未连接的端口：调整前 290 处，调整后 245 处（不含范围边界）。体检报告会逐条列出位置，多数可能是末端未建模或封堵。
