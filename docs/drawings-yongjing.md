工具：

## 1. 图纸与模型对齐

- **方法：** 图纸与模型的轴网间距序列自动匹配，得到旋转加平移的变换，不需要人工指定基点。
- **结果：** 两个方向的主轴网（1–33、A–AK）各 33 根全部匹配，误差小于 20 mm；图纸相对模型旋转 57.239°。
- **检查：** 叠合后车位落在柱网之间，车道流线位于车位排之间，机电管线沿车位排上方敷设，见叠合图。

## 3. 设计说明中的排布要求

| 专业 | 条文（摘要） | 与当前规则的关系 |
| --- | --- | --- |
| 喷淋 | 无吊顶区域采用 K80 标准响应**直立型**喷头；溅水盘与顶板距离 **75–150 mm**，梁间布置确有困难时不应大于 550 mm | 新增：喷淋支管标高受顶板控制，不能随意下降 |
| 喷淋 | 梁、通风管道、成排管道、桥架等障碍物**宽度大于 1.2 m**，其下方应增设喷头 | 新增：宽桥架 / 成排管线并排宽度超过 1.2 m 时需在下方增设喷头，排布应尽量避免 |
| 喷淋 | 支吊架与喷头距离不宜小于 0.3 m | R2 支吊架阶段 |
| 给水 / 消防 | 自喷管道宜有 ≥ 0.002 坡度坡向立管或泄水装置 | 目前喷淋管按水平有压管处理（模型坡度为 0） |
| 给水 / 消防 | 管网末端最高点、起伏聚集空气的管段峰点设**自动排气阀** | 每处向上翻弯会产生一个峰点，需要加排气阀；排气阀属于易漏节点，不得位于桥架正上方。翻弯方向应优先向下 |
| 电气 | **强弱电线槽或桥架之间净距不小于 300 mm** | ⚠ 与已确认的强弱电净距 50 mm 冲突 |
| 电气 | 桥架正常水平敷设时**底边不宜低于 2.5 m**；与梁或风管交叉时底边不应低于 2.2 m（非行车区域，且应征得建设单位认同） | 新增：桥架底标高控制，且行车区域要求更严 |
| 电气 | 桥架（线槽）与风道交叉时**上返**绕行，并保证能打开盖板 | 新增：桥架翻越风管，与“风管在上层”的偏好相反 |
| 电气 | 电缆槽盒、母线槽上方有排管交叉时应采取防水措施，**间距不小于 200 mm**，并设防水遮挡板；母线连接处上方应避开水管、喷淋头等漏水点 | ⚠ 与已确认的强电–水净距 150 mm 不一致（交叉时 200 mm） |
| 电气 | **母线槽不应安装在水管正下方** | 与“不允许长距离平行覆盖”一致，对母线为硬约束 |
| 电气 | 母线底边不应低于 2.2 m | 已满足（2.2 m 硬下限） |
| 电气 | 车道照明线槽 75 × 50 吸顶安装 | 车道上方顶板下有照明线槽 |
| 给排水 | DN65 及以上管道设抗震支吊架：侧向间距 12 m，纵向 24 m | R2 支吊架阶段 |

## 4. 需要工程师确认

1. **强弱电桥架净距：** 设计说明为 300 mm，按人工模型校准并确认的是 50 mm。以哪个为准？
2. **桥架底标高：** 设计说明要求“不宜低于 2.5 m”。是否作为桥架的标高下限（软约束 2.5 m，硬约束 2.2 m）？
3. **水管在桥架上方交叉：** 间距 200 mm 并加防水挡板（设计说明），还是 150 mm（已确认）？
4. **车道净高：**
   - 设计说明对行车区域的要求比非行车区域严；
   - 试算按车道 2.4 m（加横担 0.1 m）控制时，走廊 C 无解，A、E 有解；
   - 车道的控制值请给定。
5. **桥架与风管交叉：** 按设计说明桥架上返。是否取消“风管优先放上层”的偏好？
