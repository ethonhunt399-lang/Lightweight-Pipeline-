## 建议页序（8 页）

1. **封面：** 管综工作台。规则驱动的机电管线综合辅助工具，阶段成果（2026-10）。
2. **要解决的问题与做法：** 用流程图说明。
   - 管综依赖人工经验、耗时、难复核；
   - 本工具用规范规则驱动求解，结果可复现、每条规则可追溯，Claude 负责规则配置、解释和复核。
3. **一个真实地下室：** 规模、导出与检测速度（读入加检测约 2.5 分钟），施工图叠合。
4. **全地下室车道净高：**
   - 49 条车道逐条统计；
   - 人工方案把车道主档从 2.45–2.55 m 提到 2.55–2.70 m，横穿车道的排烟风管统一压在约 2.48 m；
   - 这是方案研讨的直接依据。
5. **自动排布方案：** 车道主档 2.60 m（净高优先），与人工方案相当。断面三联图：原模型、自动方案、人工方案。
6. **可复核：**
   - 同一套规则既检查自动方案，也复核人工方案，例如调整后模型净距不足、水管在桥架上方；
   - 每个方案列出碰撞、净距、节点和可施工性。
7. **现状与局限：**
   - 自动方案在节点细部仍有碰撞（三条走廊净高最优方案：8–37 处，人工方案 1–3 处）；
   - 回写 Revit 开发中；
   - 目前只在一个项目上验证。
8. **下一步与合作方式：** 节点库（端部整体重排）、回写 Revit、更多项目试点；欢迎试点项目。

## 表述注意

- **可以说：**
  - 规则驱动、结果可复现、可追溯；
  - 车道净高统计与人工方案复核已可实用；
  - 自动方案净高达到人工方案水平。
- **不要说：**
  - 全自动管综；
  - 零碰撞；
  - 可替代人工；
  - 已在多个项目验证。
- **数据来源：** 所有截图都来自雍景致臻江东地下室模型。对外展示前请确认甲方或设计院是否同意；不能展示时，隐去项目名和轴号。
- **三维截图里的碰撞列表：** `view3d_C_headroom.png` 右侧的碰撞列表是整个导出范围的数字，不是走廊 C 的方案碰撞数。展示时裁掉，或注明口径。
