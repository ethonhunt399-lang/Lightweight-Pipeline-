SLBH Revit -> Blender Bridge 2020 v0.2.0 源头性能优化版
=====================================================

一、这一版解决什么
------------------
1. Revit端将重复FamilyInstance改为“原型网格 + 实例变换”导出。
   适合喷头、风口、阀门、灯具、支吊架、设备、家具、门窗等重复族。
2. 相同几何、相同基础材质、相同系统着色的实例，只在prototypes.obj中保存一次网格。
3. Blender端每个构件仍可独立选择和查询，但共享同一个Mesh Data。
4. 直圆管/圆风管继续使用参数化低面数重建。
5. 导出时可以自主命名；同名目录存在时自动生成 _001、_002，不再静默覆盖。
6. 增加快速、标准、精细三种导出预设，并向Blender传递小构件轻量提示。
7. 保留v0.1.6已有的系统分类、Revit着色、中央空调语义纠正、重复集合合并和性能工具。

二、重要说明
------------
- 必须同时更新Revit端和Blender端，并重新从Revit导出。
- v0.2导出包新增 prototypes.obj；旧版Blender插件无法使用源头实例功能。
- 本版减少“重复几何数据”，但仍保留独立Blender对象，因此Outliner中的对象数量不会消失。
- 对超多对象的进一步优化（Geometry Nodes批量实例/渲染代理）留在下一阶段。
- 这是首次源头数据结构升级测试版，请先用模型副本测试。

三、Revit 2020安装
-----------------
1. 彻底关闭Revit 2020。
2. 完整解压本压缩包到英文或简短路径。
3. 双击 INSTALL_REVIT2020.cmd。
4. 显示 INSTALL SUCCESSFUL 后打开Revit 2020。
5. 使用：SLBH工具 -> Blender桥接 -> 导出到 Blender。

四、Revit导出
-------------
1. 激活非透视三维视图；剖面框、隐藏和过滤器决定导出范围。
2. 选择预设：
   - 快速：全楼、鸟瞰、超大机电模型。
   - 标准：推荐，兼顾管理和效果。
   - 精细：局部机房、近景。
3. 在“另存为”窗口直接填写导出包名称。
4. 若同目录已有同名包，自动生成 名称_001.slbh，不覆盖旧结果。
5. 导出包内容：
   project.json       BIM属性、系统、材质、实例变换、统计
   model.obj          墙板梁管件等唯一几何
   prototypes.obj     重复族原型网格（每种原型仅一份）

五、Blender 4.5安装
------------------
1. 关闭Blender。
2. 删除旧目录：
   %APPDATA%\Blender Foundation\Blender\4.5\scripts\addons\slbh_revit_bridge
3. 打开Blender：编辑 -> 偏好设置 -> 插件 -> 从磁盘安装。
4. 选择 Blender_Addon 文件夹中的v0.2.0插件ZIP。
5. 启用“SLBH Revit桥接”，建议重启一次Blender。

六、Blender导入建议
-------------------
- 集合组织：楼层 -> 专业 -> 系列
- 材质显示：Revit着色
- 圆管精度：标准
- 导入轻量方案：标准轻量
- 重复族共享网格：开启
- 小构件视口模式：包围盒

导入完成提示中：
- “源头实例”表示来自Revit原型+实例数据。
- “共享原型”表示实际只创建了多少份族网格。
- project.json 的 performance 字段记录估算避免的重复面数。

七、第一轮重点验收
-----------------
1. 喷头、风口等同类型构件位置和旋转正确。
2. 选中多个同原型对象时，Object Data名称相同。
3. 材质、Revit着色和系统分类正确。
4. 导出文件体积、导入时间、内存占用相较旧版明显下降。
5. 若发现某个族位置错位，请记录族名、类型和截图；该族可在后续加入“强制唯一几何”黑名单。
