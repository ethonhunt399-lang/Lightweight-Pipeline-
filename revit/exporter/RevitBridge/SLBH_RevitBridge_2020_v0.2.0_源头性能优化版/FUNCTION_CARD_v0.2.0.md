# SLBH Revit → Blender Bridge v0.2.0 功能卡

## 产品目标
将Revit 2020当前三维视图转换为更轻、更易管理的Blender 4.5工程。优先减少重复机电族几何，而不是保留Revit贴图或实时同步。

## Revit端
- 当前非透视三维视图导出。
- 自主命名桥接包；同名自动递增。
- 快速/标准/精细预设。
- 直圆管和圆风管参数化输出。
- FamilyInstance原型识别：局部网格哈希、材质签名、系统着色签名。
- 相同原型只写一次 `prototypes.obj`。
- 每个实例保留4×4变换矩阵、ElementId、楼层、系统和着色。
- 导出性能统计和避免重复面数估算。

## Blender端
- 兼容v0.1旧包和v0.2新包。
- `prototype_instance`直接创建共享Mesh对象。
- 中文短命名，后台保留Revit属性。
- 楼层→专业→系统系列集合。
- 写实、Revit着色、SLBH系统配色。
- 直圆管低面数重建。
- 小构件包围盒/线框显示。
- 同类别、同族、同类型、同系统、同原型选择。
- 重复网格后处理和高负担族统计仍保留。

## v0.2.0暂不做
- 实时同步与回写。
- 自动Geometry Nodes批量渲染代理。
- 复杂弯头、三通参数化重建。
- 贴图传递和UV还原。
- 自动按楼层分成多个独立桥接包。
