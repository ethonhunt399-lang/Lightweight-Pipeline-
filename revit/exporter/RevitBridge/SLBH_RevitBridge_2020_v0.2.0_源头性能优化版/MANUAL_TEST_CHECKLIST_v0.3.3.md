# SLBH Revit Bridge v0.3.3 Manual Test Checklist

## 安装与版本
- Revit 2019 安装包可以安装并加载。
- Revit 2020 安装包可以安装并加载。
- Blender 4.5 LTS 可以安装 `slbh_revit_bridge_blender_v0_3_3.zip`。
- Blender 插件显示版本为 0.3.3。

## 导入与源模型结构
- 导入全楼机电 `.slbh` 包。
- 项目根集合下存在：
  - `00_BIM源模型`
  - `10_整体展示代理`
  - `20_系统图代理`
  - `30_局部精细模型`
  - `灯光`
  - `相机`
  - `出图场景`
- `00_BIM源模型` 下仍可按来源模型、楼层、专业、系统系列管理对象。
- 任意源对象都保留 ElementId、UniqueId、楼层、专业、系统、族、类型、来源模型等属性。
- 源对象包含 `slbh.is_source_object = true`。

## 整体展示代理
- 点击“扫描当前源模型”，Text Editor 中生成 `SLBH_展示代理小构件扫描`。
- 使用默认范围“全部源模型”创建整体展示代理。
- `10_整体展示代理` 中生成代理对象。
- 生成后 `00_BIM源模型` 默认隐藏，`10_整体展示代理` 默认显示。
- 代理对象包含 `slbh.overall_display_proxy = true`。
- 代理对象包含合并规则、来源集合、来源文档和成员数量等自定义属性。

## 性能统计
- Text Editor 中生成 `SLBH_整体展示代理统计`。
- 记录：
  - 源对象数量
  - 当前可见源对象数量
  - 唯一 Mesh 数量
  - 源模型 polygon 数
  - 代理对象数量
  - 代理 polygon 数
  - 过滤构件数量
  - 低模替换数量
  - 对象数量下降比例
  - polygon 下降比例
- 统计值必须来自真实 Blender 对象和 Mesh 数据。

## 显示切换
- “源模型”只显示 `00_BIM源模型`。
- “代理”只显示 `10_整体展示代理`。
- “同时”同时显示源模型和代理。
- “全隐藏”同时隐藏源模型和代理。
- “大模型模式”隐藏源模型、显示整体展示代理，并关闭对象名称等额外视口叠加。

## 正确性
- 删除整体展示代理后，`00_BIM源模型` 仍完整存在。
- 多次创建/更新整体展示代理，不产生重复代理对象或 `.001` 垃圾集合。
- 代理按楼层、专业、系统系列和材质分块，不把全楼同材质对象合成一个超大对象。
- 喷头、支吊架、螺栓等默认不进入整体展示代理。
- 风口、小阀门等默认变成低模箱体代理。
- 主干风管、管道、桥架、线管和主要设备保留在整体展示代理中。
- 链接模型代理位置与源模型位置一致。
- 材质、Revit 着色或系统配色在代理中能保持基本可读。
- Cycles 渲染时关闭源模型，只渲染整体展示代理。
